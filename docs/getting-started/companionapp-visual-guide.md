# CompanionApp Visual Guides

Use these guides to configure a proxy and explore requests and telemetry in CompanionApp.

## TL;DR

- [Add a host](companionapp-add-host.md) to connect a backend.
- [Assign models and APIs](companionapp-model-routing.md) and [set model prices](companionapp-model-costs.md).
- [Send requests](companionapp-investigator.md) and explore [reports](companionapp-tokenomics-reports.md), [runtime activity](companionapp-runtime-monitoring.md), and [request details](companionapp-request-details.md).
