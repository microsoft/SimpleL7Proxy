# Contributing

Build, test, and understand SimpleL7Proxy before submitting a change.

## TL;DR

- [Run the proxy locally](../getting-started-developer/README.md), then read [Development](development.md) for tuning guidance.
- Read [Architecture](architecture.md) before changing request processing.
- Run the checks in [Testing](testing.md) before opening a pull request.

| Goal | Guide |
|------|-------|
| Run locally with .NET or Docker | [Run the Proxy Locally](../getting-started-developer/README.md) |
| Set up a contributor environment | [Development](development.md) |
| Locate major components and request flow | [Architecture](architecture.md) |
| Validate a change | [Testing](testing.md) |

Internal design records are kept under [`../internal/design-notes/`](../internal/design-notes/).
