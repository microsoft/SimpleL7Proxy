# How-to Guides

Use these guides to complete a specific deployment or configuration task.

## TL;DR

- Configure backends, App Configuration, or request security.
- Deploy to Azure Container Apps or as a sidecar.
- Use common scenarios and the simulator for repeatable setups.

| Task | Guide |
|------|-------|
| Configure backend routing and resilience | [Configure Backends](configure-backends.md) |
| Configure warm and cold settings | [Configure Azure App Configuration](configure-app-configuration.md) |
| Configure inbound validation and security | [Configure Security](configure-security.md) |
| Deploy to Azure Container Apps | [Deploy to Azure Container Apps](deploy-container-apps.md) |
| Deploy proxy and health sidecars | [Deploy as a Sidecar](deploy-sidecar.md) |
| Apply a complete configuration scenario | [Common Scenarios](common-scenarios.md) |
| Run a test backend | [LLM Simulator](llm-simulator.md) |
