# Alternative Deployment Paths

For a new deployment, use the [prebuilt package](../../deployment/README.md). These guides describe alternative paths; some refer to scripts that are no longer in the repository.

- [Interactive deployment](interactive-deployment.md): run deployment stages individually.
- [Custom package from CompanionApp](custom-package.md): generate deployment parameters and templates.
- [Container deployment](deploy-container-apps.md): older Azure deployment approaches; some referenced scripts are missing.
- [Sidecar deployment](deploy-sidecar.md): older sidecar approach; its deployment scripts are missing.
- [CompanionApp on App Service](companionapp-app-service.md): deploy CompanionApp separately through the portal or [Azure CLI](companionapp-app-service-cli.md).
