Tokenomics Metrics Lookup Endpoint

Status: Implemented by MetricsServer.
Base path: /tokenomics/metrics

Query parameters:
- {userId}: URL-encoded user identifier.
- {model}: URL-encoded model identifier.

GET /tokenomics/metrics/lookup?u={userId}&m={model} -> MetricsLookupResponse containing all current lookup values for the user/model combination.

Metric Upload Endpoints

Current local collapse interval: 1 second.
Proposed upload interval: 5 seconds.
Each upload covers [windowStartUtc, windowEndUtc) and contains only new deltas or samples from that window.
Batch upload paths omit {userId}; each entry contains its userId (where applicable) so one request can upload all active users.
Upload envelope: batchId, sourceId, windowStartUtc, windowEndUtc, entries.

POST /tokenomics/metrics/upload -> Single push call covering token/spend deltas, request outcomes, and model-throttle deadlines | Entry: kind, userId, model, dayUtc, inputTokens, outputTokens, costUsd, statusCode, latencyMs, retryAfterSeconds, wakeUtc, timestampUtc
- kind "rollup" uses: userId, model, dayUtc, inputTokens, outputTokens, costUsd
- kind "outcome" uses: userId, model, statusCode, latencyMs, timestampUtc
- kind "modelThrottle" uses: model, retryAfterSeconds, wakeUtc, timestampUtc

Upload rules:
- The receiver deduplicates by sourceId and batchId.
- A retry reuses the same sourceId, batchId, window, and entries.
- The sender retains a batch until the receiver returns a successful 2xx response.
- The sender does not upload cumulative daily or monthly totals as deltas.
- The receiver derives UTC daily and monthly totals from dayUtc and costUsd.
